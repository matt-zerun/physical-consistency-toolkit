# External dependencies

No third-party source or bundled dependency binary is redistributed in the source
archives. Installation obtains separately maintained dependencies. This inventory
records package families and their generally distributed license identifiers;
consult the exact installed distribution's license for the authoritative terms.

| Dependency | Role | License family |
|---|---|---|
| Python | runtime and standard library | Python Software Foundation |
| NumPy | numerical arrays | BSD-3-Clause |
| pandas | tables and CSV | BSD-3-Clause |
| SciPy | convex-hull triangulation | BSD-3-Clause |
| scikit-learn | regressors, split and CV | BSD-3-Clause |
| Matplotlib | plots | Matplotlib license (PSF-based) |
| openpyxl (optional) | XLSX input | MIT |
| XGBoost (optional) | boosted trees | Apache-2.0 |
| Plotly.py (optional) | offline interactive surfaces | MIT |
| setuptools, wheel | package build tools | MIT |

The MIT grant for this project does not relicense dependencies. No external images,
article graphics, trained models or datasets are redistributed. Review exact
resolved dependency notices when preparing any binary or installer distribution.
